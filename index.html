THE PROJECT

Rent a computer at the shop.

A Computer Shop Rental System for managing in-store PC rentals, session time, and customer transactions at an internet café.

PROPOSED SYSTEM

Choose a shop PC.
Rent it by the hour.

Customers select an available PC at the shop and choose how long they need to use it on-site. The system calculates the rental fee using the hourly rate.

01Check computer availabilityView which computers are available or occupied.
02Start and manage a sessionChoose rental hours, calculate the fee, extend time, check remaining time, or end a session.
03Handle customer paymentCheck if payment is enough and calculate the change due.
04Process more customersKeep the rental system running for multiple customers and transactions.
PROGRAMMING CONCEPTS
CONDITIONALSCheck availability, rental time, and payment.
SWITCHHandle rent, extend, check time, and end-session actions.
LOOPSContinue processing customers until the system closes.
